# Simulador Mundial 2026

Simulador de partidos del Mundial 2026 desarrollado como parte del curso de JavaScript. Este proyecto permite simular resultados de partidos entre equipos, visualizar la tabla de posiciones y practicar conceptos de programación con JS, HTML y CSS.

## 🛠️ Tecnologías utilizadas

- **HTML** para la estructura del simulador  
- **CSS** para el diseño y estilo  
- **JavaScript** para la lógica de simulación y manejo de resultados
